# meshMovement

Python module for **online structured mesh adaptation** during an OpenFOAM simulation. It is called at every timestep by the `structuredPythonMotionSolver` C++ motion solver via pybind11, receives the current flow fields, and returns a displacement vector that OpenFOAM applies to the mesh.

---

## Entry Point

```
meshMovement/
└── RefineMesh.py     ← imported and called by the motion solver
```

`RefineMesh.py` must be present in the **OpenFOAM case root** at runtime. Copy or symlink the entire `meshMovement/` directory there before launching the solver.

## IMPORTANT NOTE
```
The geometry described in the Case MUST be identical to the one described when using the mesh generation software. IF not all fails, but it is easy to check. 
```
---

## How It Fits into the Simulation

```
OpenFOAM (structuredPythonMotionSolver)
        │
        │  at each timestep passes:
        │    - current mesh point coordinates
        │    - structured-to-OpenFOAM index map
        │    - flow fields (U, p, vorticity)
        │    - logical grid indices (i, j)
        ▼
  RefineMesh.py
        │  1. Reconstruct 2-D structured grid (X, Y) from OpenFOAM point data
        │  2. Compute refinement sources (Jameson sensor, Ducros sensor)
        │  3. Build φ/ψ attraction potentials from Thomas–Middlecoff weights
        │  4. Run Winslow elliptic smoother to redistribute grid points
        │  5. Compute and return displacement vectors (deformation field)
        ▼
OpenFOAM applies displacement to all mesh points
```

## Refinement Sensors

### Jameson Pressure Shock Sensor (`_jameson_sensor`)

Detects compression waves using a second-difference of pressure:

```
f = |p_{i+1} - 2p_i + p_{i-1}| / |p_{i+1} + 2p_i + p_{i-1}|
```

Active only in regions with `p_{i-1} > p_{i+1}` (compression). Output is clipped to `[0, 1]` and normalised against the 99.99th percentile.

### Ducros Vorticity Sensor

Supplied by the C++ solver as part of the flow-field data. It distinguishes vortex cores from shock fronts and is used together with the Jameson sensor to drive φ/ψ.

Both sensors are cached to `ducros_cache/` and `phi_cache/` for post-processing.

---

## Winslow Solver

`TTM/TTMSolver.py` contains both the original **TTM** solver (used in mesh generation) and the **Winslow** solver used here for mesh movement. The Winslow variant supports:

- Periodic φ/ψ recomputation during the iteration (`RECOMPUTE_INTERVAL`)
- Partial Neumann activation (`NEUMANN_BOT_FRACTION`) to relax boundary nodes along a prescribed curve
- Boundary projection via KDTree-based snapping to the original curves

## Parameters

Key variables at the top of `RefineMesh.py`:

| Variable | Description |
|----------|-------------|
| `CASE_PATH` | Path to the OpenFOAM case (set before copying to the case) |
| `MeshResolution` | `(Nx, Ny)` — must match the mesh generated by `meshGeneration` |
| `N_INNER` | Max Winslow iterations per timestep |
| `NEUMANN_ITERATIONS` | How many Winslow iterations apply the Neumann BC (0 = Dirichlet only) |
| `TOL` | Convergence tolerance |
| `OMEGA` | SOR over-relaxation factor |
| `RECOMPUTE_INTERVAL` | Re-interpolate φ/ψ every N iterations during the solve (0 = disabled) |
| `C2_Xi` / `C2_Eta` | Second-order weight amplification in ξ / η |
| `C_DUCROS` | Ducros sensor amplification factor |
| `XI_CUTOFF` / `ETA_CUTOFF` | Logical coordinate beyond which the flow-field has no effect on the grid |
| `NEUMANN_BOUNDARY` | Bool array `[bot, top, left, right]` for Neumann-active sides |
| `NEUMANN_BOT_FRACTION` | Fraction of bottom boundary that is Neumann-free (rest stays fixed) |

## Module Structure

```
meshMovement/
├── RefineMesh.py                  # entry point (called by motion solver)
├── Geometry/
│   ├── ParametrisizedCurves.py    # curve primitives
│   ├── clusterFunctins.py         # arc-length clustering
│   └── Cases/                     # domain geometry definitions
├── TTM/
│   ├── TTMSolver.py               # Winslow/TTM solver loop
│   ├── ThomasMiddlecoff.py        # weight functions, φ/ψ, Jameson sensor
│   ├── NeumannSolver.py           # ghost-cell Neumann BC
│   ├── BoundaryProjection.py      # KDTree curve snapping
│   ├── HelperFunctions.py         # metric coefficients, TDMA
│   └── stitchBoundaryDictionary.py
└── meshGenerationFiles/
    ├── CellPointGeneration.py     # point array generation
    ├── WriteStructuredMeshFiles.py # write updated structuredMesh directory
    ├── generatePointFields.py     # map OpenFOAM points → structured grid
    └── loadData.py                # cache loading for helper curves
```
